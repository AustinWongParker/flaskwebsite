How to update website
--------------------
The site is hosted for free on GitHub Pages. GitHub rebuilds and publishes it
automatically every time you push to master (see .github/workflows/pages.yml).

1. Edit the pages in templates/ (or add images to static/).
2. Preview it locally: flask run, then open http://127.0.0.1:5000/
   (setup steps are in starting_flask.txt)
3. Commit and push to master.
4. Open the "Actions" tab on GitHub. When the run turns green (about a minute),
   the live site is updated.

Adding a new page:
- Add a route in app.py that returns render_template('yourpage.html').
  build.py finds every route on its own and saves it as yourpage.html.
- Link to it with href="yourpage", like the other menu links.

Images and files:
- Only files in static/ that a page links to get published to the live site.
  Anything else in static/ stays off the website, but is still visible to
  anyone browsing the public GitHub repo.

To test the build yourself: python build.py (the output goes to _site/)
