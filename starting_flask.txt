Quick Start: https://flask.palletsprojects.com/en/stable/quickstart/

First time on a new computer
~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. python -m venv venv
2. Activate it:
   - Windows:    venv\Scripts\activate
   - Mac/Linux:  source venv/bin/activate
3. pip install -r requirements.txt

Running the site locally
~~~~~~~~~~~~~~~~~~~~~~~~
1. Activate the virtual env (step 2 above)
2. flask run          (Flask finds app.py on its own, no FLASK_APP needed)
3. Go to http://127.0.0.1:5000/

Debug mode (reloads the page when you save a file): flask run --debug
